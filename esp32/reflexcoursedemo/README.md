# ESP32 Reflex Course Demo

This is the complete student ZIP for the Reflex Guard Course 1 demo.

## Files

- `reflexcoursedemo.ino` - ESP32 firmware for the course demo.
- `MonogateDashboard.exe` - student dashboard for viewing live ESP32 serial data.
- `schematic.md` - reference schematic.
- `wiring-diagram.md` - direct pin-to-component wiring map.
- `BOM.md` - bill of materials.

## Quick Start

1. Open `reflexcoursedemo.ino` in the Arduino IDE.
2. Select your ESP32 board and upload the sketch.
3. Double-click `MonogateDashboard.exe`.
4. Turn the potentiometer and press the button while watching the dashboard.

Safety: unplug USB before moving jumper wires. If you smell anything hot or see
smoke, unplug the board immediately and check the wiring before powering it
again.
