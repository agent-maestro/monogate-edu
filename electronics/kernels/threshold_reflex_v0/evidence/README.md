# Evidence Checklist

For a student packet, include:

- trace JSONL;
- validation output;
- short video or screenshot;
- pin map;
- firmware or simulator source;
- claim boundary;
- SHA-256 manifest.

Claim boundary:

```text
This is a low-voltage educational bench demonstration.
It does not claim certified safety, autonomous deployment, or high-power
actuator control.
```
