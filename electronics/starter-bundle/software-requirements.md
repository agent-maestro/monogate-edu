# Software Requirements

## Required For All Learners

- Modern browser: Chrome, Edge, or Brave.
- Python 3.
- A way to download the repo: Git or a GitHub ZIP download.

## Required For The Interactive Lab And Dashboard

- Node.js LTS.
- npm, included with Node.js.

Run the app from the repo root:

```powershell
cd apps\electronics-lab
npm install
npm run dev
```

Then open:

```text
http://127.0.0.1:5173/electronics
```

## Required For ESP32 Physical Builds

- Arduino IDE or Arduino CLI.
- ESP32 board support.
- USB data cable, not charge-only.
- Permission to access the serial port.

## Optional For Contributors

- VS Code.
- Playwright for browser tests.
- GitHub Actions knowledge for validation workflow changes.
