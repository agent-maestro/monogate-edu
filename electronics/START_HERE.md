# Start Here

Welcome to Monogate Electronics.

This repo teaches guarded physical computing with one repeated loop:

```text
input -> kernel -> guard -> output -> trace -> replay -> evidence
```

## Choose Your Path

If this is your first Monogate Electronics course, start with the
[Starter Bundle](starter-bundle/README.md). It explains the software,
hardware, dashboard, trace, replay, and evidence habits that courses share.

If you already know the shared workflow, go straight to the
[Course Index](COURSE_INDEX.md).

If you are beginning with hardware, start with
[001 Reflex Guard](courses/001-reflex-guard/README.md).

## What You Need First

- A modern browser.
- Python 3 for validators and replay tools.
- Node.js LTS only if you want to run the interactive lab/dashboard locally.
- Course-specific hardware only when a course asks for it.

## Safety Boundary

Courses are low-voltage learning labs. Do not use mains voltage, relays,
motors, actuators, or unfamiliar wiring unless a course explicitly provides
that path and you understand the stop conditions.
