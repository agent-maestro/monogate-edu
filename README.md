# Monogate Edu

Public learner-facing Monogate education materials.

This repo is exported from private working repos. It should stay clean,
classroom-readable, and free of private planning notes, local captures, funding
packets, and machine-specific paths.

## Topics

- [Electronics](electronics/START_HERE.md)

## Download

Use GitHub's current-main ZIP when you do not want to clone:

```text
https://github.com/agent-maestro/monogate-edu/archive/refs/heads/main.zip
```

Do not host a static ZIP copy on the website. The GitHub ZIP keeps learners on
the current public `main` branch.
